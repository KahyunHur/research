# additive manufacturing

## Definition
Additive manufacturing, commonly known as 3D printing, is a process of creating three-dimensional objects by adding material layer by layer. Instead of cutting or drilling away from a solid block, a computer guides a machine to build the object from the bottom up using materials like plastic, metal, or resin. This allows for the creation of complex and customized shapes that would be difficult or impossible to make with traditional manufacturing methods.
